### [D - Swap and Range Sum](https://atcoder.jp/contests/abc442/tasks/abc442_d)

> ### Problem Statement
>
> You are given a sequence A=(A1,A2,…,AN) of length N.
>
> Process Q queries in order. Each query is in one of the following formats:
>
> - `1 x` : Swap the values of Ax and Ax+1.
> - `2 l r` : Find the value of l≤i≤r∑Ai.
>
> ### Constraints
>
> - 2≤N≤2e5
> - 1≤Q≤5e5
> - 1≤Ai≤1e4
> - For queries of the first type, 1≤x≤N−1.
> - For queries of the second type, 1≤l≤r≤N.
> - All input values are integers.
>
> ------
>
> ### Input
>
> The input is given from Standard Input in the following format:
>
> ```
> N Q
> A1 A2 … AN
> query1
> query2
> ⋮
> queryQ
> ```
>
> Here, queryi represents the i-th query and is given in one of the following formats:
>
> ```
> 1 x
> 2 l r
> ```
>
> ### Output
>
> Let q be the number of queries of the second type, and output q lines. The i-th line (1≤i≤q) should contain the answer to the i-th query of the second type.

#### 分析：

​	这题应该是让我们来模拟运算的，就如下两个操作：第一个是交换现在相邻的两个数，第二个是输出当前的求和的值。主要问题在于数据量不小。我们尝试使用两个数组完成，其中一个用于标记顺序的变化。嗯就酱紫。

​	交题目的时候想了一下，这是D题，哪里会这么简单...果然tle了。让我们换一个思路，用前缀和来试试？刚刚好可以优化掉加和这一步的重复操作。

​	前缀和的核心操作是预处理，我们可以在一开始导入数据的时候就开始计算从第一项到此项的加和，在后面交换的时候，可以这样来操作。

```c++
int sum[200005];

sum[i] = sum[i - 1] + a[i];

// 交换时
swap(a[x], a[x + 1]);
sum[x] = sum[x - 1] + a[x];
```

#### 代码：

```c++
#include <iostream>
using namespace std;

int a[200005];
int sum[200005];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(nullptr);

    int n, q;
    cin >> n >> q;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        sum[i] = sum[i - 1] + a[i];
    }

    for (int i = 0; i < q; i++) {
        int opr;
        cin >> opr;
        if (opr == 1) {
            int x;
            cin >> x;
            swap(a[x], a[x + 1]);
            sum[x] = sum[x - 1] + a[x];
        }
        else if (opr == 2) {
            int x, y, temp = 0;
            cin >> x >> y;
            temp = sum[y] - sum[x - 1];
            cout << temp << "\n";
        }
    }
    return 0;
}
```

### [I - Two Languages](https://atcoder.jp/contests/abc441/tasks/abc441_b)

> ### Problem Statement
>
> The AtCoder country has two official languages: Takahashi-go and Aoki-go.
>
> Both Takahashi-go and Aoki-go use some lowercase English letters to write words in those languages. Takahashi-go uses only the characters contained in a string S of length N, and Aoki-go uses only the characters contained in a string T of length M.
>
> You are given Q words w1,w2,…,wQ that are in the official languages of the AtCoder country. For each word, determine which of the following applies based on the characters contained in that word:
>
> - It is confirmed to be a word in Takahashi-go
> - It is confirmed to be a word in Aoki-go
> - Neither can be determined
>
> ### Constraints
>
> - 1≤N≤26 
> - 1≤M≤26
> - S is a string of length N consisting of lowercase English letters.
> - The characters in S are arranged in alphabetical order.
> - All characters in S are distinct.
> - T is a string of length M consisting of lowercase English letters.
> - The characters in T are arranged in alphabetical order.
> - All characters in T are distinct.
> - 1≤Q≤100
> - wi is a string of length at least 1 and at most 100 consisting of lowercase English letters. (1≤i≤Q)
> - wi is a word in Takahashi-go or Aoki-go. (1≤i≤Q)
> - N,M,Q are integers.
>
> ------
>
> ### Input
>
> The input is given from Standard Input in the following format:
>
> ```
> N M
> S
> T
> Q
> w1
> w2
> ⋮
> wQ
> ```
>
> ### Output
>
> Print Q lines. The i-th line should contain `Takahashi` if it is confirmed that wi is a word in Takahashi-go, `Aoki` if it is confirmed to be a word in Aoki-go, and `Unknown` if neither can be determined.

#### 分析：

​	我们首先输入两个字符串，其中的字符分别是两种语言所包含的全部字符，我们只需要判断之后输入的是否为其中一种语言即可。

​	我们可以创建两个数列，共26个元素，对于每一个字母都有0/1两个状态，如果为1说明这个语言有这个字符，0的话就没有，通过这样筛出是哪个语言的。

#### 代码：

```c++
#include <iostream>
#include <string>
using namespace std;

int vac[2][27] = {0};

int main() {
    int n, m;
    cin >> n >> m;
    
    string S;
    cin >> S;
    for (char c : S) {
        vac[0][c - 'a'] = 1;
    }
    
    string T;
    cin >> T;
    for (char c : T) {
        vac[1][c - 'a'] = 1;
    }
    
    int q;
    cin >> q;
    
    for (int i = 0; i < q; i++) {
        string word;
        cin >> word;
        
        int is_takahashi = 1;
        int is_aoki = 1;
        
        for (char c : word) {
            if (!vac[0][c - 'a']) {
                is_takahashi = 0;
            }
            if (!vac[1][c - 'a']) {
                is_aoki = 0;
            }
        }
        
        if (is_takahashi && !is_aoki) {
            cout << "Takahashi" << endl;
        } else if (!is_takahashi && is_aoki) {
            cout << "Aoki" << endl;
        } else {
            cout << "Unknown" << endl;
        }
    }
    return 0;
}
```

### [A - Calculating Part-Time Job Pay](https://atcoder.jp/contests/awc0029/tasks/awc0029_a)

> ### Problem Statement
>
> Takahashi is an accountant at a company. This company has N part-time staff members, each numbered from 1 to N.
>
> In a certain month, staff member i worked Ci shifts.
>
> The company pays each staff member a base pay of P yen per shift. However, for staff members whose monthly shift count is K or more, a special bonus of B yen per shift is added on top of the base pay for all of that staff member's shifts. In other words, staff members with K or more monthly shifts are paid a total of P+B yen per shift, while staff members with fewer than K shifts are paid P yen per shift.
>
> Find the total salary to be paid to all N staff members.
>
> ### Constraints
>
> - 1≤N≤100
> - 1≤P≤1000
> - 1≤B≤1000
> - 1≤K≤31
> - 1≤Ci≤31 (1≤i≤N)
> - All input values are integers
>
> ------
>
> ### Input
>
> ```
> N P B K
> C1 C2 … CN
> ```
>
> - The first line contains N representing the number of staff members, P representing the base pay per shift, B representing the special bonus amount per shift, and K representing the threshold of monthly shift count for the special bonus to apply, separated by spaces.
> - The second line contains C1,C2,…,CN representing the monthly shift count of each staff member, separated by spaces.
>
> ### Output
>
> Print the total salary the company pays to all N staff members on a single line.

#### 分析：

​	本题为简单的循环题，计算所有人的应发的薪资，如果加班多了还有奖励。

#### 代码：

```c++
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int N, P, B, K;
    cin >> N >> P >> B >> K;
    
    vector<int> C(N);
    for (int i = 0; i < N; ++i) {
        cin >> C[i];
    }
    
    long long all = 0;
    for (int ci : C) {
        if (ci >= K) {
            all += (long long)ci * (P + B);
        } else {
            all += (long long)ci * P;
        }
    }
    
    cout << all << endl;
    return 0;
}
```
