### [A - Repdigit](https://atcoder.jp/contests/abc444/tasks/abc444_a)

> ### Problem Statement
>
> You are given a 3-digit positive integer N. Determine whether all digits are the same when N is represented in decimal.
>
> ### Constraints
>
> - 100≤N≤999
> - The input value is an integer.
>
> ------
>
> ### Input
>
> The input is given from Standard Input in the following format:
>
> ```
> N  
> ```
>
> ### Output
>
> If all digits are the same when N is represented in decimal, output `Yes` in one line; otherwise, output `No`.

#### 分析：

​	较为简单的输入输出题，只需判断输入的三个字符是否相等即可。

#### 代码：

```c++
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(nullptr);

    char a, temp;
    a = getchar();
    temp = a;
    for (int i = 0; i < 2; i++) {
        a = getchar();
        if (a != temp){
            cout << "No";
            return 0;
        }
        temp = a;
    }
    cout << "Yes";
    return 0;
}
```

### [B - Digit Sum](https://atcoder.jp/contests/abc444/tasks/abc444_b)

> ### Problem Statement
>
> The **digit sum** of a positive integer n is defined as the sum of the digits when n is represented in decimal. For example, the digit sum of 2026 is 2+0+2+6=10.
>
> Find the number of positive integers not exceeding N whose digit sum is K.
>
> ### Constraints
>
> - 1≤N,K≤1e5
> - All input values are integers.
>
> ------
>
> ### Input
>
> The input is given from Standard Input in the following format:
>
> ```
> N K
> ```
>
> ### Output
>
> Output the answer.

#### 分析：

​	我们可以进行for循环，在其中判断每一位的加和数。

​	判断各位数量的代码可以如下：

```c++
int getDigitSum(int num) {
    int sum = 0;
    while (num > 0) {
        sum += num % 10;
        num /= 10;
    }
    return sum;
}
```

​	然后加上简单的输入输出即可。

#### 代码：

```c++
#include <iostream>
using namespace std;

int getDigitSum(int num) {
    int sum = 0;
    while (num > 0) {
        sum += num % 10;
        num /= 10;
    }
    return sum;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(nullptr);

    int n, x, count = 0;
    cin >> n >> x;

    for (int i = 1; i <= n; i++) {
        if (getDigitSum(i) == x)
            count++;
    }

    cout << count;

    return 0;
}
```

### [C - AtCoder Riko](https://atcoder.jp/contests/abc444/tasks/abc444_c)

> ### Problem Statement
>
> You are given a sequence of N positive integers A=(A1,A2,…,AN).
>
> Find all positive integers L for which the following can occur:
>
> > AtCoder Inc. has released a stick-shaped snack called "AtCoderiko." A cup contains one or more AtCoderikos, each of length L. When Takahashi shook the cup, each AtCoderiko ended up in one of the following states:
> >
> > -  It remained as one AtCoderiko of length L. 
> > -  It broke into two AtCoderikos whose lengths sum to L. Here, the length of each AtCoderiko is a positive integer.
> >
> > After shaking the cup, there were N AtCoderikos in the cup, and the length of the i-th AtCoderiko was Ai.
>
> The given input guarantees that there exists at least one positive integer L for which this can occur.
>
> ### Constraints
>
> - 1≤N≤3e5
> - 1≤Ai≤1e9
> - There exists at least one L satisfying the condition.
> - All input values are integers.
>
> ------
>
> ### Input
>
> The input is given from Standard Input in the following format:
>
> ```
> N  
> A1 A2 … AN  
> ```
>
> ### Output
>
> Output all values of L satisfying the condition in ascending order, separated by spaces, in one line.

#### 分析：

​	在这道题中，我们需要计算可能的AtCoder棒子的原长度。每个棒子都有两种来源：

​		1.继承其原来的全部长度；

​		2.折了，变成长度为1到原来长度-1之间的任意一个长度，并且一对AtCoder棒子需要满足加和为原长；

​		3.只摔了一次，即以上两个过程只发生一次。

​	由此我们可以观察到如下特点：

​		1.长度L应该在最长单个At棒子到最短棒子与最长棒子加和之间（闭区间）；

​		2.L应当是所有棒子加和的长度的一个因数（即全长可以被L整除）；

​		3.每一个当前第n小的棒子都应当可以和当前第n大的棒子结合，并且结合的长度应当等于L。

​	我们可以用一个vector来记录所有的At棒。并通过以下的函数获得关于总长的所有因数，从中进行遍历筛选。

```c++
vector <long long> count_div(long long X) {
    vector<long long> v;
    for (long long i = 1; i <= X / i; i++) {
        if (X % i == 0) {
            v.push_back(i);
            if (i != X / i) {
                v.push_back(X / i);
            }
        }
    }
    sort(v.begin(), v.end());
    return v;
}
```

​	之后我们通过分别判断上面剩余2条，即可得到结果。

​	注意需要通过双指针来进行判断，否则可能会超时。

代码：~~（可读性较弱 慎读）~~

```c++
#include <algorithm>
#include <cmath>
#include <iostream>
#include <unordered_map>
#include <vector>
using namespace std;

vector <long long> count_div(long long X);

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(nullptr);

    long long n, maxl = 0, minl = 2e9;
    long long count = 0;
    cin >> n;
    vector<long long> v(n);
    for (int i = 0; i < n; i++) {
        cin >> v[i];
        if (v[i] > maxl) maxl = v[i];
        if (v[i] < minl) minl = v[i];
        count += v[i];
    }
    sort(v.begin(), v.end());
    unordered_map<long long, int> freq;
    for (long long x : v) freq[x]++;
    vector<long long> maybe = count_div(count);
    vector<long long> ans;
    int flag = 0, left, right;
    vector<long long> confirm;

    for (long long x : maybe) {
        if (x < maxl) continue;
        confirm.clear();
        long long k = count / x;
        flag = 1;
        if (k <= n && n <= 2 * k) {
            for (long long y : v) {
                if (y != x)
                    confirm.push_back(y);
            }// 获得了去除y的所有队列
            sort(confirm.begin(), confirm.end());
            int localconfirm = confirm.size();
            if (localconfirm % 2 != 0) {
                flag = 0;
                continue;
            }
            left = 0;
            right = localconfirm - 1;
            while (left < right) {
                if (confirm[left] + confirm[right] != x) {
                    flag = false;
                    break;
                }
                left++;
                right--;
            }
            if (flag == 1)
            ans.push_back(x);
        }
    }

    for (int i = 0; i < ans.size(); i++) {
        if (i > 0) cout << " ";
        cout << ans[i];
    }
    cout << endl;

    return 0;
}

vector <long long> count_div(long long X) {
    vector<long long> v;
    for (long long i = 1; i <= X / i; i++) {
        if (X % i == 0) {
            v.push_back(i);
            if (i != X / i) {
                v.push_back(X / i);
            }
        }
    }
    sort(v.begin(), v.end());
    return v;
}
```

### [A - Count .](https://atcoder.jp/contests/abc442/tasks/abc442_a)

> ### Problem Statement
>
> You are given a string S consisting of lowercase English letters.
>
> Here, we define the number of **dots** in a lowercase English letter as follows:
>
> - If the lowercase English letter is `i` or `j`: 1 dot
> - If the lowercase English letter is neither `i` nor `j`: 0 dots
>
> Find the sum of the numbers of dots over all characters in S.
>
> ### Constraints
>
> - S is a string consisting of lowercase English letters with length between 1 and 10, inclusive.
>
> ------
>
> ### Input
>
> The input is given from Standard Input in the following format:
>
> ```
> S
> ```
>
> ### Output
>
> Print the answer.

#### 分析：

​	本题只需要一直判断输入字符，如果是i或者j就在输出数据+1，最后输入结果。

#### 代码：

```c++
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(nullptr);

    char a;
    int count = 0;
    a = getchar();
    while (a != '\n') {
        if (a == 'i' || a == 'j') count++;
        a = getchar();
    }

    cout << count;
    return 0;
}
```

### [B - Music Player](https://atcoder.jp/contests/abc442/tasks/abc442_b)

> ### Problem Statement
>
> Takahashi has a music player. Initially, the volume is 0 and the music is stopped.
>
> From now on, Q operations will be performed in order. The i-th operation is represented by an integer Ai, which means the following:
>
> - If Ai=1, increase the volume by 1.
> - If Ai=2, if the current volume is 1 or more, decrease it by 1; if it is 0, do nothing.
> - If Ai=3, if the music is stopped, play it; if the music is playing, stop it.
>
> For i=1,2,…,Q, solve the following problem:
>
> - Determine whether the music is playing at volume 3 or more immediately after the i-th operation.
>
> ### Constraints
>
> - 1≤Q≤2×1e5
> - Ai∈{1,2,3}
> - All input values are integers.
>
> ------
>
> ### Input
>
> The input is given from Standard Input in the following format:
>
> ```
> Q
> A1
> A2
> ⋮
> AQ
> ```
>
> ### Output
>
> Output Q lines. The i-th line should contain `Yes` if the music is playing at volume 3 or more immediately after the i-th operation, and `No` otherwise.

#### 分析：

​	本体需要我们判断每行输入的数字，并判断或计算其音量的变化，最后判断其音量是否大于3，输出Yes or No。

#### 代码：

```c++
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(nullptr);

    int volume = 0, n, play = 0;
    cin >> n;
    for (int i = 0; i < n; i++) {
        int temp;
        cin >> temp;
        if (temp == 1) {
            volume++;
        }
        else if (temp == 2) {
            if (volume >= 1) volume--;
        }
        else if (temp == 3) {
            if (play == 1) play = 0;
            else play = 1;
        }
        if (volume >= 3 && play == 1) {
            cout << "Yes" << '\n';
        }
        else cout << "No" << '\n';
    }
    return 0;
}
```

### [C - Peer Review](https://atcoder.jp/contests/abc442/tasks/abc442_c)

> ### Problem Statement
>
> There are N researchers, numbered 1,2,…,N.
>
> There are M conflicts of interest among the researchers; for i=1,2,…,M, researchers Ai and Bi have a conflict of interest with each other.
>
> The reviewers of a paper must be three distinct researchers who are different from the author of the paper and have no conflict of interest with the author.
>
> For i=1,2,…,N, solve the following problem:
>
> - Find the number of possible triples of reviewers for a paper authored by researcher i.
>
> Assume that all papers are single-authored.
>
> ### Constraints
>
> - 1≤N≤2×1e5
> - 0≤M≤2×1e5
> - 1≤Ai,Bi≤N
> - Ai\\=Bi
> - (Ai,Bi)\\=(Aj,Bj) if i\\=j.
> - (Ai,Bi)\\=(Bj,Aj) if i\\=j.
> - All input values are integers.
>
> ------
>
> ### Input
>
> The input is given from Standard Input in the following format:
>
> ```
> N M
> A1 B1
> A2 B2
> ⋮
> AM BM
> ```
>
> ### Output
>
> Print the answers for i=1,2,…,N in this order, separated by spaces.

#### 分析：

​	本题需要我们排除那些有利益相关的人，并计算剩余人进行评审的组合数。

​	我们可以输入的时候定义一个vector，并向其中键入每一对有利益相关的人的对数。

​	之后从中得出每一个人所对应的可以与其进行peer review的人数，再Cn3（在n个中无序选3个）的数量进行输出即可。

​	Cnj的代码实现如下：

```c++
int cn3(int n) {
    if (n < 3) {
        return 0;
    }
    return n * (n - 1) * (n - 2) / 6;
}
```

​	此时代码如下。

```c++
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int cn3(int n) {
    if (n < 3) {
        return 0;
    }
    return n * (n - 1) * (n - 2) / 6;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(nullptr);

    int n, m;
    cin >> n >> m;
    vector<vector<int>> v(n + 1);

    for (int i = 0; i < m; i++) {
        int x, y;
        cin >> x >> y;
        v[x].push_back(y);
        v[y].push_back(x);
    }// 记录每一对不可能的对数

    for (int i = 1; i <= n; i++) {
        if (i != 1) cout << ' ';
        int localcount = 0;
        for (int j = 1; j <= n; j++) {
            if (j == i) continue;
            auto it = find(v[i].begin(),v[i].end(),j);
            if (it != v[i].end()) continue;
            localcount ++;
        }
        cout << cn3(localcount);
    }

    return 0;
}
```

​	不难发现，还是有优化空间，可以将不可能对数直接在输入时从vector中移除。

​	我们可以更进一步，假设其没有重复的，则只需设计一个一维vector，在其中直接计算所剩人数！~~这就是梭哈~~ 此时代码：

    cin.tie(nullptr);
    cout.tie(nullptr);

        v[y] --;

### [H - Black Square](https://atcoder.jp/contests/abc441/tasks/abc441_a)

> ### Problem Statement
>
> There is a grid with 10100 rows and 10100 columns.
> In what follows, the cell at the i-th row from the top and j-th column from the left is denoted as cell (i,j).
>
> In this grid, only the 100×100 region with cell (P,Q) as the top-left cell is painted black, and all other cells are painted white.
> Determine whether cell (X,Y) is painted black.  
>
> ### Constraints
>
> - 1≤P,Q,X,Y≤10000
> - P,Q,X,Y are integers.
>
> ------
>
> ### Input
>
> The input is given from Standard Input in the following format:
>
> ```
> P Q
> X Y
> ```
>
> ### Output
>
> If cell (X,Y) is painted black, print `Yes`; otherwise, print `No`.

分析：

​	本题中只有在（P，Q）及其右下99格涂黑，识别是否在图黑格子里即可。注意边界条件。

代码：

```c++
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(nullptr);

    int p, q;
    cin >> p >> q;
    int x, y;
    cin >> x >> y;
    if ((x >= p && x < p + 100) && (y >= q && y < q + 100))
        cout << "Yes";
    else
        cout << "No";

    return 0;
}
```
